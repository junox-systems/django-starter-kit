Django Starter Kit

A modern, production-ready foundation for SaaS and web products: auth, API, admin, background jobs, S3 storage, email, and observability — out of the box.

Get started Admin

What's included

django-allauth with email-based login, OIDC, social sign-in, and email verification. Custom UUID user model.

django-modern-rest with session auth, msgspec serialization, and OpenAPI schema generation.

Django's built-in admin with import/export, object permissions, and change history.

django-q2 workers with Postgres as the queue — send email, build exports, and process long-running work off the request path.

django-storages behind one Storage API: local disk, S3, Azure or GCS. Swap with an env var.

Sentry error tracking and OpenTelemetry traces (OTLP) — ready for ClickHouse, Grafana, or any collector.
